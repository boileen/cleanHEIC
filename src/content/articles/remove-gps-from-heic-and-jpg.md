# How to Remove GPS Location From HEIC and JPG Photos

A photo can reveal where it was taken even after it has been resized. Removing GPS and EXIF data is a separate concern from changing the file format.

## Quick answer

Re-encode the image rather than editing metadata in place, then inspect the exported file with a metadata viewer to confirm location fields are gone.

## Step-by-step workflow

### Step 1: Classify the image before processing

Treat IDs, medical images, private family photos, location-bearing photos and confidential records as sensitive.

### Step 2: Evaluate the processing method

Check whether a tool runs locally or sends files to a server and review published retention and deletion terms.

### Step 3: Export using tested settings

For a JPEG output, compare image dimensions, compression artefacts, colour and metadata against your real needs.

### Step 4: Verify rather than assume

Use a metadata viewer or file inspector to verify privacy, GPS removal, orientation and embedded profiles where relevant.

## How this applies to your situation

### Privacy is an implementation question

A converter describing itself as private is not enough. Understand where processing occurs and inspect the actual exported metadata.

## Common mistakes to avoid

- Changing only the filename: The bytes inside a HEIC container do not become JPEG merely because the suffix is changed.
- Deleting the only original: A new JPEG may be resized or missing metadata. Keep the source until the output is fully checked.
- Assuming every export keeps all metadata: Location, date, orientation and colour information may be copied, removed or rewritten depending on software.
- Ignoring the final application: A technically valid JPEG still may fail a portal because of maximum size, dimensions or aspect-ratio requirements.

## Frequently asked questions

### Does converting a photo remove its GPS data?

A converter that rebuilds the image from decoded pixels strips embedded metadata. A tool that edits metadata in place may not.

### Will the image look exactly the same after conversion?

JPEG compression and colour processing can change pixels, even when the image has the same dimensions. Test an output at your intended viewing size.

### Will changing the extension from HEIC to JPEG work?

No. An extension rename does not perform image decoding and JPEG encoding.

### Can I keep the original photo?

Yes, and that is recommended. Export a new compatible copy to a different folder.

### What if the target website still rejects the file?

Confirm the file really is JPEG, then check size, dimensions, colour mode, corruption and the website’s current requirements.

## Final checklist

- Original HEIC safely retained
- Export is a genuine JPEG file
- Output opens in an independent viewer
- Dimensions, colour and orientation checked
- Metadata and privacy requirements reviewed
- Target service accepts the result
